# HA Monthly Audit

屋邨樹木缺陷離線記錄（屋邨、日期、樹號碼、defect）。資料只存在你部電話或 iPad 嘅瀏覽器，唔會上載到伺服器。可按日期分類／篩選，並匯出 Excel。

呢個係獨立應用，並非複製 Tree Assessment Schedule，但操作風格同現場用法接近：大掣、單手／手指或 Apple Pencil 都方便，適合 Android 電話同 iPad mini。

## 點樣打開

用瀏覽器打開呢個資料夾嘅 `index.html` **之前**，最好用一個本地或網站伺服器（Service Worker 同「加入主畫面」喺 `file://` 唔會生效）。例如喺呢個資料夾執行：

```bash
python3 -m http.server 8080
```

然後用 Chrome 或 Safari 打開 `http://本機或伺服器位址:8080/`。

正式使用建議放上 HTTPS 網站（例如 GitHub Pages），再用瀏覽器「加入主畫面」，當一個 App 打開。

## 加入主畫面

第一次用網絡打開並等頁面載入完成之後，先做以下步驟。之後無網絡都可以繼續用（包括匯出 Excel）。

### Android（Chrome）

1. 用 **Chrome** 打開網站。
2. 撳右上角選單（⋮），揀 **加入主畫面** 或 **安裝應用程式**。
3. 之後由主畫面圖示打開即可。無網絡都可以用。

### iPad / iPhone（Safari）

請用 **Safari** 打開（唔好用其他 App 內嵌瀏覽器）。iPad mini 建議用直向或橫向都可以，畫面會自動排成「左邊輸入、右邊記錄」。

1. 用 **Safari** 打開網站。
2. 撳分享按鈕（方框加向上箭咀）。
3. 揀 **加入主畫面**。
4. 名稱可用預設「HA Audit」，撳加入。之後由主畫面圖示打開，狀態列會以獨立 App 方式顯示。

若要用 Apple Pencil 喺欄位手寫，請喺「設定 > Apple Pencil」開啟 **Scribble（隨手寫）**。

## 離線同資料安全

- 第一次成功載入後，應用程式同 Excel 元件會缓存喺裝置，之後飛行模式都可以新增、更改、刪除同匯出。
- 記錄存在本機 IndexedDB，重新整理或關閉 App 都仲喺。
- **清網站資料、刪 App、換機或還原裝置就會冇記錄。** 請定期「匯出 Excel」或喺「更多」下載 JSON 備份。
- 加入主畫面之後，資料通常比只係開住 Safari／Chrome 分頁更穩陣。建議日常用主畫面圖示打開。

## 點樣用

1. **揀屋邨**：撳屋邨欄，用搜尋或負責人（davy / Felix / Lynn）過濾。名單有 75 個屋邨（來源係 11 月 Monthly 清單，但應用程式唔鎖死月份，每條記錄有自己嘅日期）。
2. **日期**：預設今日，可改，或撳「今日」。連續錄同一日會保留日期同屋邨。
3. **樹號碼**：直接輸入；可用 T / AT / TG 前綴掣。
4. **Defect**：可自由輸入，或撳常用項目，亦可以「搜尋全部缺陷清單」多選。多項會用 `; ` 分隔。
5. 撳 **儲存記錄**。儲存後會清樹號碼同 defect，方便跟住錄下一棵。
6. 若同一屋邨、同一日、同一樹號碼已有記錄，會提示你更新，或加到現有 defect。
7. **記錄**頁按日期分組（新至舊），可再篩選日期、屋邨、負責人，並顯示數量。
8. **匯出目前**只匯出而家篩選結果；**匯出全部**匯出所有記錄。檔名例如 `HA-Monthly-Audit-2026-11-24.xlsx`。欄位包括：屋邨、日期、樹號碼、Defect、負責人、建立時間、更新時間。
9. 「更多」提供 JSON 備份／還原（合併或全部取代），同清除全部記錄（會先確認）。

更改或刪除單條記錄要喺記錄卡片操作；刪除前會再確認。

## 畫面（電話同 iPad）

- **電話直向**：上方有「新增 / 記錄」分頁，大掣、大字，方便戶外單手用。
- **iPad（包括 iPad mini，直向同橫向）**：輸入表同記錄列表並排，用多出嚟嘅空間睇到今日已錄項目，唔使不停轉頁。對話框唔會拉成全螢幕。觸控目標保持夠大，適合手指或 Apple Pencil。

## 備註

- 屋邨後綴係「邨」，名單按照來源檔。來源檔入面「天耀」兩項寫法較亂，已按「天瑞(一)邨／天瑞(二)邨」正規化為 **天耀(一)邨**、**天耀(二)邨**。
- 負責人只係可選嘅標記同篩選，記錄欄位本身係屋邨名稱。
- Defect 快捷詞彙取自現有現場用語清單，並非官方表格編號；清單以外嘅內容一律可以手打。
